Build a complete working prototype for the project:

**“AI-Based Network Attack Forecasting from Network Traffic Data”**

### Project Objective

Develop an AI-powered cybersecurity system that analyzes network traffic data, identifies abnormal traffic patterns, and forecasts the possibility of a cyber attack before or during its early stages. The system should provide an attack type, prediction probability, risk level, and early warning alert through a web dashboard.

### Core Workflow

Network Traffic Data
→ Data Collection
→ Data Preprocessing
→ Feature Extraction
→ Time-Window Analysis
→ AI/ML Prediction
→ Attack Forecasting
→ Attack Type Classification
→ Risk Score Calculation
→ Early Warning Alert
→ Dashboard Visualization
→ Preventive Action

### Dataset

Use the **CIC-IDS2018 dataset** for training and testing.

The system should:

* Load network traffic CSV data.
* Handle missing values and duplicate records.
* Encode categorical features.
* Scale numerical features where required.
* Select relevant network traffic features.
* Split data into training and testing sets.
* Handle class imbalance where necessary.
* Train an appropriate machine-learning model.
* Save the trained model for prediction.

### AI/ML Requirements

Implement a practical ML pipeline suitable for a prototype.

The model should:

1. Analyze network traffic features.
2. Identify whether the traffic is normal or suspicious.
3. Classify the possible attack type.
4. Generate a prediction probability.
5. Convert the prediction into a risk score.
6. Use time-window-based traffic patterns to support forecasting rather than only simple packet-level classification.

Possible attack categories include:

* Benign
* DDoS
* DoS
* Brute Force
* Botnet
* Infiltration
* Web Attack
* Other attack classes available in the dataset.

Use an appropriate model such as Random Forest, XGBoost, Gradient Boosting, LSTM, or another suitable model. Clearly explain why the selected model is appropriate.

### Forecasting Logic

The system should not simply display “Attack Detected.”

It should provide a forecasting-oriented output such as:

**Normal Traffic**
Risk Score: 15%
Status: LOW

**Suspicious Traffic**
Risk Score: 68%
Status: MEDIUM
Warning: Possible attack activity detected.

**High Risk**
Risk Score: 91%
Status: HIGH
Warning: Cyber attack likely. Immediate preventive action recommended.

Use recent traffic observations/time windows to calculate trends and improve the forecasting concept.

### Backend

Create a Python-based AI service/API using **FastAPI or Flask**.

Required API functionality:

* Health check
* Upload network traffic data
* Run preprocessing
* Run prediction
* Return attack type
* Return probability
* Return risk score
* Return risk level
* Return traffic statistics
* Return forecasting result

Example API response:

{
"prediction": "DDoS",
"probability": 0.91,
"risk_score": 91,
"risk_level": "HIGH",
"forecast": "Attack likely",

}
